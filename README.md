RenameToolは、指定されたフォルダ内のすべてのファイル名に、部門コードと日付をプレフィックス（接頭辞）として一括で追加するためのシンプルなGUIアプリケーションです。
ファイル管理の標準化と整理を支援します。

新しいファイル名の形式
リネーム後のファイル名は以下の形式になります。

[部門コード]_[YYYYMMDD]_[元のファイル名].[拡張子]
例:
元のファイル名: report.pdf
入力情報: 部門コード: SALES、日付: 20240115
新しいファイル名: SALES_20240115_report.pdf

🛠️ 必須要件
本ツールを実行するには、以下の環境が必要です。
Python 3.x
tkinter (Python標準ライブラリに含まれています)

使い方 (How to Use)
1. セットアップ
本ツールは、リネームのオプションを定義するための**Setting.py**ファイルに依存しています。
renameTool.pyと同じディレクトリに、以下の構造を持つ**Setting.py**を作成してください。
Python

Setting.py の例

実行時にデフォルトで表示される対象フォルダ
DEFAULT_TARGET_FOLDER = ""  # 例: "C:/Users/User/Documents/TargetFolder"

プルダウンメニューに表示する部門コードのリスト
(コードと説明をスペースで区切ることを推奨)
DEPARTMENT_CODES = [
    "SALES 営業部",
    "DEV 開発部",
    "ADMIN 管理部",
    # 必要に応じて追加
]
2. ツールの実行
コマンドラインまたはターミナルで、renameTool.pyファイルがあるディレクトリに移動し、以下のコマンドを実行します。

Bash

python renameTool.py
3. アプリケーションの操作
対象フォルダの選択: 「参照」ボタンをクリックし、リネームしたいファイルが入っているフォルダを選択します。
部門コードの選択: プルダウンメニューから適切な部門コードを選択します。（リネーム時に使用されるのは、先頭のスペースまでの文字列です。例: SALES）
日付の入力: YYYYMMDD形式（例: 20240115）で半角数字8桁の日付を入力します。
実行: 「実行」ボタンをクリックすると、指定フォルダ内のすべてのファイルにリネームが適用されます。

注意: この操作は元に戻せません。重要なファイルを扱う前に、必ずバックアップを取るか、テスト用のフォルダで動作確認を行ってください。
